# 🌐 Estudos e Desafios — HTML & CSS

Repositório criado para armazenar meus **estudos, exercícios, desafios e pequenos projetos** desenvolvidos durante meu aprendizado de **HTML5 e CSS3**.

O objetivo deste repositório é acompanhar minha evolução no desenvolvimento web, colocando em prática os conceitos aprendidos através de exercícios e projetos próprios.

* 🔵 **CSS3** — Estilização, layouts e responsividade
